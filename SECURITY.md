# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
support@marketing2themax.co.za. Do not open a public GitHub issue containing
personal information, credentials, exploit details, or registration data.

Include the affected URL, the behaviour observed, reproduction steps, and the
potential impact. M2M will acknowledge the report and coordinate remediation
and disclosure directly with the reporter.

## Supported deployment

Security updates are applied to the current production deployment from the
`main` branch.
